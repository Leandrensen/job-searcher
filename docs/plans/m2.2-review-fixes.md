## Key code
- `src/db/companies.ts`: `insertOrGetCompany(db, c, nowIso): number`. It returns the existing id for (`ats`, `slug`) unchanged, otherwise inserts with `status: "active"`. It's called by `recordResolution` (case `"confirmed"`) and `addManualCompany` (new companies only).
- `src/db/companies.ts`: `recordCompanyFetch`. After 3 consecutive `not_found` outcomes it sets the company to `inactive`, closes its open jobs, and resets its candidate to `pending` with `companyId: null`.
- `src/db/companies.ts`: `listDueCompanies(db, ats, nowIso, { force?, minHours? })`. Returns only `status = "active"` companies.
- `src/db/schema.ts`: `companies` columns `status` (`"active" | "inactive"`), `consecutiveFailures`, `lastError`, `lastFetchedAt`.
- `src/sources/ats-runner.ts`: `runAtsSources`. Per company it calls `runAdapter`, filters `result.jobs` into `kept`, then in one transaction calls `upsertJobs(tx, kept, nowIso, { companyId })` and `markClosedJobs(tx, company.id, kept.map((j) => j.externalId), nowIso)`. It logs `${ats}/${slug}: kept N, filtered T+L, closed C`. `result.invalid` counts items that failed `itemSchema`, `normalize` or `JobSchema`.
- `src/sources/ats-runner.test.ts`: `fakeAts(id, boards)` (items are `{ id, title, workplaceType?, regions? }`, validated by a Zod schema), `addCompany(ats, slug, homeCountry?)`, `run(adapters, { force?, at?, log? })`, `company(slug)`, `GOOD` (5 items: 2 stored), `T0`, `hoursLater(h)`.
- `src/scripts/company-cli.ts`: `parseCommand`. `add <ats> <slug>` and `confirm <candidateId> <ats> <slug>` pass `slug` through exactly as typed.
- `src/companies/slugs.ts`: `PATTERNS` and `extractAtsRefs`. SmartRecruiters keeps case (`keepCase: true`); every other ATS slug is lowercased.
- `src/companies/resolve.ts`: `proveIdentity(candidate, ats, probe)`. Rule 3 (Lever and Ashby only) builds `nameRe` from `candidate.name.trim()`, case-insensitive and whole-word, and needs mentions in `Math.min(2, texts.length)` postings.
- `src/core/dedupe.ts`: `stripLegalSuffixes(name)`. It returns the name lowercased and trimmed, with trailing legal suffixes (`inc`, `llc`, `gmbh`, ...) removed, and never returns an empty string for a non-empty name.

## Tasks

### T1: A re-confirmed company is reactivated
- Depends on: none
- Files: `src/db/companies.ts`, `src/db/companies.test.ts`
- Behavior: in `insertOrGetCompany`, when the (`ats`, `slug`) row exists **and** its `status` is `"inactive"`, update it to `status: "active"`, `consecutiveFailures: 0`, `lastError: null`, then return its id. Don't touch `lastFetchedAt`; an inactive company's last fetch is at least days old, so it's due anyway. An active existing row is returned unchanged, as today.
- Failure cases: an unknown company is still inserted as today. Its closed jobs stay closed until the next successful fetch reopens them through `upsertJobs`; no extra code is needed.
- Tests first (`companies.test.ts`, `describe("companies")`):
  - `insertOrGetCompany reactivates an inactive company`: add `greenhouse/acme`, record 3 `not_found` outcomes (`{ kind: "not_found", error: "HTTP 404" }`), then call `insertOrGetCompany` with the same ats/slug. It returns the same id, and the row matches `{ status: "active", consecutiveFailures: 0, lastError: null }`.
  - `a candidate re-confirmed to a deactivated company makes it due again`: confirm candidate "Acme" to `greenhouse/acme` via `recordResolution`, deactivate it with 3 `not_found` outcomes at `T0`, and check `listDueCompanies(db, "greenhouse", plusDays(T0, 1))` is `[]`. Then call `recordResolution(db, candidateId, { status: "confirmed", ats: "greenhouse", slug: "acme", companyName: null }, plusDays(T0, 1))`. Now `listDueCompanies(db, "greenhouse", plusDays(T0, 1)).map((c) => c.slug)` equals `["acme"]`, and the candidate matches `{ status: "confirmed", companyId: <the same id> }`.
  - `insertOrGetCompany leaves an active company unchanged`: after 1 `not_found` outcome (`consecutiveFailures: 1`), `insertOrGetCompany` returns the id and the row still has `consecutiveFailures: 1` and `lastError: "HTTP 404"`.
- Verify: `npm test -- src/db/companies.test.ts` passes.
- Commit: `fix(m2): reactivate a company when it is confirmed again (M2.2 T1)`
