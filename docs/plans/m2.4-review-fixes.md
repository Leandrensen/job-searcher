# M2.4: Fixes from the fourth M2 code review

Base: commit `ed44d98` on branch `feat/m2-companies-ats`. Executed with the `execute-plan` skill.

## Goal
Fix four problems before the M2 PR is opened:
1. Ashby links with characters outside the slug pattern (like `%20`) are cut short, and the shortened slug is trusted.
2. Rate-limit skips count toward a candidate's error backoff.
3. Common-word company names ("Front", "Ramp") prove unrelated Lever/Ashby boards through posting text.
4. The 404 counter isn't reset by other errors, so non-consecutive 404s can deactivate a company.

- Decisions already made:
  - **T1:** Ashby slugs need the same end-of-slug check as Lever. A link whose slug runs into another character (`%`, `&`, ...) yields no ref, rather than a shortened slug.
  - **T2–T3:** a resolution whose **only** probe errors were rate limits (HTTP 429, or the resolve runner's skip after a 429) is still status `error` and retried the next day, but it doesn't increase `consecutiveErrors`. If any probe failed for another reason, it counts as today.
  - **T4–T5:** the Lever/Ashby name proof (rule 3) becomes **case-sensitive** and treats a hyphen as part of a word. The name is matched exactly as written, with legal suffixes stripped but its case kept. So "Front" no longer matches "front-end" or "Front-end", and "Ramp" doesn't match "ramp up". Names styled differently in postings (candidate "ACME", postings "Acme") no longer match and go to manual review; that's accepted for precision.
  - **T6:** any fetch outcome other than a 404 resets `consecutiveFailures` to 0, so only 3 404s in a row deactivate a company. A 429 skip records nothing (unchanged).

- T1: the lookahead must sit after a **lazy** `+?`. A greedy `+` followed by the lookahead backtracks into the same truncation bug.
- T3: `tryProbe` catches the error before the runner sees it, so classify inside `tryProbe`. Don't rely on the `firstError` string.
- T3: T3 touches 4 files, because the runner's thrown error class has to change together with the resolver's classification.
- T5: no `"i"` flag. Keep the `"u"` flag, because `\p{L}` needs it.
- T5: the escaping must stay. Names like "A.Team" or "dbt Labs (YC)" contain regex characters.
- T6: the `ats-runner.test.ts` test named `a non-404 error waits a day and keeps the failure count` starts at 0 failures, so it still passes. Don't rename it (out of scope).
