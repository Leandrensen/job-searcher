# M3.3: Rank a duplicate once its original closes

Base: commit `9676578` on branch `feat/m3-ranking`. Executed with the `execute-plan` skill.

## Goal
`listOpenJobsForRanking` skips a job marked as a duplicate **only while its original is still open**. When the original closes, the still-open duplicate is ranked again, so a live posting never disappears from `npm run rank` (or, later, from scoring). If several open duplicates share a closed original, only the oldest (lowest id) is ranked, so the job still appears once.

- Decisions already made:
  - **A job counts as a duplicate only while its original is open.** `upsertJobs` sets `duplicateOf` once at insert and never changes it, and there's no need to rewrite it: the read query decides.
  - **One copy per closed original:** among open duplicates of the same closed original, keep the lowest id. Ordering by id makes the result deterministic and stable.
  - **A dangling pointer** (`duplicateOf` naming a row that doesn't exist) counts as "the original is gone", so the job is ranked. Jobs are never deleted, so this is only defensive.

## Key code
- `src/db/ranking.ts`: `listOpenJobsForRanking(db): RankableJob[]`. It selects 11 fields from `jobs`, `where(and(isNull(jobs.closedAt), isNull(jobs.duplicateOf)))`, ordered by `asc(jobs.id)`. It imports `and, asc, inArray, isNull` from `drizzle-orm`, and `jobEmbeddings, jobs` from `./schema`.
- `src/db/schema.ts`: `jobs.duplicateOf` (`integer("duplicate_of").references(() => jobs.id)`) and `jobs.closedAt` (`text`, null = open).
- `src/db/queries.ts`: `upsertJobs` sets `duplicateOf` via `findOriginal` only on insert. A job with the same company and title from **another source** within 30 days points at the oldest open original that isn't itself a duplicate.
- `src/db/ranking.test.ts`: `makeJob(externalId, over)` (source `"greenhouse"` by default), `NOW`, and `db`. The existing `describe("duplicates")` has `skips jobs marked as a duplicate of another`, where job 1 is the Greenhouse original, job 2 the Lever duplicate, and the expected result is `[1]`.
- Drizzle self-join: `import { alias } from "drizzle-orm/sqlite-core"; const original = alias(jobs, "original");`, then `.leftJoin(original, eq(original.id, jobs.duplicateOf))`.

## Gotchas
- **Use a left join, not an inner join.** An inner join would drop every non-duplicate job, since its `duplicateOf` is null.
- **The alias must be distinct** (`alias(jobs, "original")`). Joining `jobs` to itself without one makes the `where` columns ambiguous.
- **Strip `duplicateOf` before returning.** `rank-cli` and `embedJobs` take `RankableJob`, and the exact-fields test checks the shape.
- **Ordering matters for picking the oldest duplicate.** Apply the "already kept" check after ordering by `jobs.id` ascending.
